# Python Projects — Super Bowl & TV Data Analysis

Exploratory data analysis in Python investigating Super Bowl game outcomes, TV viewership trends, and halftime show musicians using `pandas` and `matplotlib`.

## Project Structure

```text
python-projects/
├── tv data.py         # Super Bowl, TV ratings, and halftime show analysis
├── requirements.txt   # Python dependencies
├── LICENSE
└── README.md
```

## Tech Stack

- **Language:** Python 3
- **Libraries:** `pandas`, `matplotlib`

## Getting Started

```bash
git clone https://github.com/zizo1414/python-projects.git
cd python-projects
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

> **Note:** `tv data.py` expects CSV datasets under `datasets/` (`super_bowls.csv`, `tv.csv`, `halftime_musicians.csv`).
